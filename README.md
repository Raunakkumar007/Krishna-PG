# 🏠 Krishna PG

A modern, responsive and animated PG (Paying Guest) accommodation website built using React and Vite.

Krishna PG provides a clean and interactive platform where students and working professionals can explore rooms, check facilities, view the location, and directly contact the PG for enquiries.

## 📌 Project Overview

**Krishna PG** is a modern single-page accommodation website designed to provide complete information about a PG in a simple and attractive way.

The website includes:

- Premium PG accommodation information
- Room categories and pricing
- Facilities and amenities
- Photo gallery
- Testimonials
- Location and Google Maps integration
- Direct phone calling
- WhatsApp enquiry
- Email contact
- Online enquiry form
- Responsive design
- Smooth animations and hover effects

The main goal of the project is to create a professional digital presence for Krishna PG and make it easier for potential residents to get information and contact the PG.
